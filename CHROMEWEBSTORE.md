## Privacy & Data Use

### Data Collection

**Does the extension collect user data?** No

Nothing leaves the device. The extension makes no network requests. It only loads its own bundled `contemplations.json`. Favourites, the pinned contemplation, the shuffle order and journal text are stored in the browser's local storage for the extension, on the user's device only.

## Review Notes

### Before submitting

- Bump `version` in `manifest.json` (required for every upload after the first), commit, and push a matching tag, e.g. `git tag v0.1.0 && git push origin v0.1.0`. The Release workflow attaches `still-<version>.zip` to the GitHub Release. Download it from there and upload it to the dashboard. `scripts/package.sh` builds the same zip locally.
- Fill in the TODOs above (visibility, publisher, contact email).

### Known Issues / Limitations

- **Third-party content (review risk).** The contemplations are Brahma Kumaris "Thought for Today" texts, transcribed verbatim from shivbabas.org, and the listing names Brahma Kumaris. Confirm you have permission to redistribute them, or at least that attribution is acceptable, before publishing. The store acts on IP and trademark complaints, and a listing can be taken down if the owner objects.
- Contemplations are bundled, not fetched, so new ones arrive only with an extension update.
